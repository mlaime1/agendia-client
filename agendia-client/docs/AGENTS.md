# Agendia coding notes

## Goals

- keep files small
- prefer reusable components
- preserve feature-based structure
- do not place all logic inside screen files

## UI philosophy

- simple
- clean
- lightweight
- fast

## Calendar rules

- cells summarize information
- max 3 visible trip stamps
- extra trips use +N
- quick action bar remains active
- normal tap creates trip
- long press opens day details
- special trip opens modal
